> 项目定位：基于 **FastAPI + Vue 3 + TypeScript** 的全栈快速开发平台，深度封装企业级 Web 应用的通用能力（认证、权限、审计、通知、公告、文件、监控、开放平台、AI 助手），让开发者聚焦业务本身。

## 二、一期功能全景

### 1. 认证与用户体系
- JWT 令牌认证（登录 / 退出 / 刷新），密码哈希存储；
- 登录安全：邮箱验证码二次认证、滑块校验、记住账号密码（前端 localStorage）；
- 用户 CRUD（创建 / 更新 / 删除 / 禁用启用 / 重置密码）、分页查询、关键词搜索；
- 个人中心：基础资料、头像、修改密码、最近登录记录、最近操作记录、通知偏好设置。

### 2. RBAC 权限体系
- 角色管理：超管 / 管理员 / 普通用户，角色 CRUD 与权限勾选；
- 权限管理：权限清单按模块归类（中文 + 英文标识），菜单管理；
- **权限自动注册**：路由函数通过 `@permission` 装饰器声明，启动时自动扫描并同步至 `permissions` 表，路由移除后标记 `is_deprecated`；
- **实时鉴权**：接口通过 `Depends(require_user_permission("module:action"))` 校验，超管 `*` 通配短路；
- 越权访问统一返回标准权限异常，普通用户默认不可见仪表盘等管理能力。

### 3. 审计与日志
- 操作审计：用户 / 角色 / 权限 / 通知 / 公告 / 文件等关键行为全量入 `audit_logs`；
- 登录日志：登录成功 / 失败记录（用户名、姓名、IP、时间、结果）；
- 列表支持关键词、状态、时间范围过滤；**CSV 导出**（文件名带年月日时分秒后缀、中文表头、备注列加宽）；
- 个人中心展示最近登录记录与最近操作记录（含用户名 + 姓名）。

### 4. 通知中心
- 系统通知管理：**普通通知** 与 **系统维护通知** 两类，支持发布 / 撤回 / 列表 / 详情；
- 系统维护通知：维护时间（时间选择器，不得早于当前时间）+ 维护时长 + 维护原因，自动组合生成正文，无需手工填写；
- **站内信**：广播至全部用户，15s 轮询拉取 + 未读红点，标记已读；
- 多渠道推送：站内信 / 邮件 / 钉钉 / 飞书 / 短信（抽象渠道接口，可扩展）；
- 用户通知偏好：按事件类型配置启用渠道（站内信默认开启）；
- 通知失败自动重试（Redis 队列 + 后台 Worker）。

### 5. 公告管理
- 公告 CRUD：创建 / 编辑 / 删除 / 发布 / 下架 / 详情 / 列表；
- 正文支持 **Markdown 与富文本** 两种格式；
- 有效期设置（开始 / 结束时间），过期自动下架；
- 展示形态：首页横幅（Banner）与首页板块，公告与通知在展示层明确区分；
- 发布 / 编辑 / 上架 / 下架 / 删除均纳入操作审计。

### 6. 文件管理
- 文件上传 / 下载 / 删除，分页列表，本地与 S3 兼容存储抽象；
- 文件管理页面视觉与用户管理一致（统一卡片容器）；
- 上传 / 下载 / 删除均纳入操作审计，日志导出支持文件维度。

### 7. 仪表盘
- 用户 / 角色 / 开放应用统计卡片；
- 登录趋势、操作日志趋势（ECharts 可视化）；
- 系统监控（并入仪表盘页面），普通用户不可见。

### 8. 开放平台
- 开放应用管理：AppId / AppKey 生命周期、密钥轮换、scope 授权；
- 双鉴权模式：**plain**（明文）与 **hmac**（HanJiang-1 HMAC 签名）；
- 签名协议：`Ver + METHOD + URI + Content-Type + Date + SHA256(body)`，Content-Type 固定 `application/json`，时间窗 300s 防重放；
- 探活接口：`/health` `/version` `/me` `/ping`；业务接口：`/users` 系列（scope 校验）；
- 配套高质量演示客户端（`examples/openapi_client.py`，默认演示 GET + POST + DELETE 全链路）与《开放平台对接指南》（Python / Go 对接步骤）。

### 9. AI 助手
- SSE 流式对话（token / navigate / done 事件），会话管理、记忆压缩、知识库检索、工具编排；
- `openai_compat` 协议，可对接 DeepSeek / 火山方舟 / 通义 / vLLM 等；
- 对话质量 👍👎 反馈，接口纳入权限控制。

### 10. 全局搜索与运维
- 全局搜索：支持 **用户 / 文件 / 通知 / 公告** 多类型检索；
- 系统告警（alert）、健康检查（数据库 / 缓存连通性）、版本探针、Swagger 文档。

## 四、系统架构

```
前端（Vue3 管理后台）               前端（开放平台对接方）
        │                                 │
        ▼                                 ▼
  /api/v1（用户态）                /api/open/v1（开放平台）
        │                                 │
        ▼                                 ▼
   ┌─────────────────────────────────────────────┐
   │  API 路由层（api/）：入参接收、鉴权、统一响应      │
   ├─────────────────────────────────────────────┤
   │  业务逻辑层（services/）：规则校验、事务编排      │
   ├─────────────────────────────────────────────┤
   │  数据访问层（repositories/）：CRUD、分页过滤     │
   ├─────────────────────────────────────────────┤
   │  ORM 实体层（models/）+ 基础设施层（infras/）    │
   └─────────────────────────────────────────────┘
                     │
        ┌────────────┼────────────┐
        ▼            ▼            ▼
      MySQL        Redis      存储 / 通知渠道 / LLM
```

- **五层单向依赖**：API → Services → Repositories → (Models + Infras)，禁止跨层调用；
- **全局支撑**：`core/`（配置、日志、异常、中间件）、`constants/`（常量与枚举）、`utils/`（工具）、`schemas/`（Pydantic 模型）；
- 数据库 / Redis / 存储 / 通知渠道均基于**抽象基类定义接口契约**，实现可替换、可 Mock。

## 六、接口概览

- **用户态 `/api/v1`**：78 个 HTTP 端点，覆盖认证、用户、角色、权限、通知、公告、文件、审计、登录日志、仪表盘、个人中心、开放应用管理、AI 助手、全局搜索、告警、健康检查；
- **开放平台 `/api/open/v1`**：9 个端点（探活 4 个 + 用户管理 5 个），走独立 AppId/AppKey 鉴权与 scope 校验；
- 全局统一响应结构 `BaseResp`（code / message / data / timestamp / request_id）；
- 统一异常处理：404 / 405 / 500 / 限流 / 权限异常全部转换为标准 JSONResponse，不暴露服务端堆栈。

## 八、一期核心亮点

1. **权限体系自动化**：装饰器声明 + 启动自动注册 + 实时鉴权，新增接口只需声明权限标识，零手工维护；
2. **双面消息体系**：通知（站内信推送 + 多渠道）与公告（首页展示 + 有效期）职责分离，模型与页面各自清晰；
3. **开放平台可演示**：HMAC 签名协议 + 高质量示例客户端 + 对接指南，第三方接入成本低；
4. **审计全覆盖**：通知发布 / 撤回、公告创建 / 编辑 / 上架 / 下架 / 删除、文件上传 / 下载 / 删除等关键行为均有留痕；
5. **体验打磨**：品牌色统一 #409eff、自定义 Logo、各页面统一卡片容器与按钮样式、CSV 导出列宽与表头优化；
6. **工程质量**：分层架构约束、全量类型注解、统一日志与异常、78+ 端点全部权限可控、pytest 测试通过、ruff 静态检查通过、Docker 一键部署。
